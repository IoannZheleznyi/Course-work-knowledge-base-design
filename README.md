# SpiceSearch

Курсовая работа: "Проектирование базы знаний для специй".
Выполнил: студент Железный Иоанн Александрович СДП-ИИ-241

## Возможности

- Поиск информации о специях.
- Получение описаний из базы знаний.
- Поиск изображений через Wikimedia Commons.
- Поиск видеоматериалов.
- Получение актуальных новостей о специях.
- Объединение результатов из базы данных и интернет-источников.

## Используемые технологии

- Python 3.14
- Flask
- PostgreSQL
- SQLAlchemy
- HTML, CSS, JavaScript
- Wikimedia Commons API
- YouTube Data API
- Google News RSS

## Запуск проекта

1. Склонировать репозиторий.
2. Создать виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активировать окружение:

   ```bash
   source .venv/bin/activate
   ```

4. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Создать файл `.env` и указать настройки подключения к PostgreSQL и необходимые API-ключи.

6. Заполнить базу данных:

   ```bash
   python seed.py
   ```

7. Запустить приложение:

   ```bash
   python run.py
   ```

8. Открыть в браузере:

   http://127.0.0.1:5000

Для хранения информации используется PostgreSQL.
